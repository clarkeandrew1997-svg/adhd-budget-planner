# ADHD Budget Planner

A calm, accessible budget dashboard inspired by an ADHD-friendly money-management experience.

## Run locally

Open `index.html` directly in a browser, or start a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Features

- Today's available-spending overview
- Upcoming bills
- Transaction history
- Add income or expense transactions
- Responsive mobile navigation
- Bills, plan, and insights views
